# ⏱️ Neon Stopwatch

A modern and visually appealing **Neon Stopwatch Application** built using **HTML, CSS, and JavaScript**. This project features a glowing neon-themed interface, precise time tracking, lap recording functionality, and responsive design for a smooth user experience across different devices. :contentReference[oaicite:0]{index=0}

## 🚀 Project Overview

The Neon Stopwatch is a web-based timing application designed to measure elapsed time with centisecond precision. The application provides essential stopwatch functionalities such as Start, Stop, Reset, and Lap recording while maintaining an attractive neon-inspired user interface.

This project helped strengthen my understanding of JavaScript timing functions, DOM manipulation, event handling, and modern UI design principles. :contentReference[oaicite:1]{index=1}

## 🎯 Functionalities

### Start Button
Starts the stopwatch and begins counting time.

### Stop Button
Pauses the stopwatch while preserving the current time.

### Reset Button
Resets the stopwatch to `00:00:00` and clears all recorded laps.

### Lap Button
Records the current stopwatch time and stores it in the lap history section. :contentReference[oaicite:2]{index=2}
